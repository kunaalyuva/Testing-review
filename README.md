# 📝 AiReadmeGen

AiReadmeGen is an intelligent command-line tool that leverages the power of Large Language Models (LLMs) via Ollama to automatically generate comprehensive and professional `README.md` files for your projects. It streamlines the documentation process, ensuring your projects have clear, well-structured, and informative READMEs from the start.

## ✨ Features

*   **AI-Powered Content Generation**: Utilizes local LLMs (via Ollama) to intelligently analyze project context and generate relevant README sections.
*   **Dynamic Markdown Output**: Produces well-formatted Markdown (`.md`) files, ready for GitHub or any Markdown viewer.
*   **PDF Conversion Capability**: Automatically converts the generated Markdown README into a professional PDF document for alternative distribution.
*   **Modular Design**: Separates concerns for AI interaction, markdown processing, and file output for easy maintenance and extension.
*   **Project Structure Analysis**: Infers project details and structure to inform the README content generation.

## 🛠️ Tech Stack

*   **Primary Language**:
    *   Python
*   **AI/ML**:
    *   Ollama (for local LLM inference)
*   **Core Libraries**:
    *   Standard Python Libraries (for file operations, string manipulation, etc.)
    *   Python Markdown/PDF Libraries (for converting Markdown to PDF)

## 🏗️ Architecture

AiReadmeGen follows a script-based, modular architecture designed for sequential processing. The `main.py` script acts as the orchestrator, coordinating the various components to achieve the README generation and conversion.

1.  **Orchestration (`main.py`)**: The entry point that initiates the project analysis and calls upon the AI model for content generation.
2.  **AI Model Interaction (`ollama_model.py`)**: Responsible for interfacing with the Ollama server, sending prompts, and receiving generated text from the LLM.
3.  **Markdown to PDF Conversion (`markdown_to_pdf.py`)**: Takes the generated Markdown content and transforms it into a `Output.pdf` file.
4.  **File Operations (`new_file.py`)**: Handles the creation and writing of the generated Markdown content to a `.md` file, and potentially other file-related utilities.

This design ensures clear separation of concerns, making each part of the generation pipeline manageable and focused on a specific task.

## 🚀 Getting Started

Follow these instructions to get a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites

Before you begin, ensure you have the following installed:

*   **Python 3.8+**: Download from [python.org](https://www.python.org/downloads/).
*   **Ollama**: Install Ollama and a suitable model (e.g., `llama2`, `mistral`) locally. Follow the instructions on the [Ollama website](https://ollama.com/download). Ensure the Ollama server is running before using AiReadmeGen.

    ```bash
    ollama run mistral # or llama2, etc.
    ```

### Installation

1.  **Clone the repository**:

    ```bash
    git clone https://github.com/your-username/AiReadmeGen.git
    cd AiReadmeGen
    ```

2.  **Install Python dependencies**:
    While a `requirements.txt` is not provided, you will likely need to install libraries for Ollama client interaction, Markdown parsing, and PDF generation.

    ```bash
    pip install ollama markdown reportlab # Example, adjust as needed
    ```

### Running the Application

1.  **Ensure Ollama server is running** and your chosen model is downloaded (e.g., `ollama run mistral`).
2.  **Execute the main script**:

    ```bash
    python main.py
    ```

    The application will then prompt you for necessary information or automatically generate the README based on its internal logic. Upon completion, you will find `README.md` and `Output.pdf` in the project directory.
